# 🎨 Cover Studio Pro - Thiết Kế & Render Ảnh Bìa Creator

Ứng dụng web chuyên nghiệp hỗ trợ thiết kế và render ảnh bìa/thumbnail đa tỷ lệ (**16:9** cho YouTube/Facebook, **9:16** cho TikTok/Reels/Shorts, **1:1** cho Podcast/Instagram) với các công nghệ Typography Pro và Canvas UX hiện đại.

---

## 🌟 Các Tính Năng Nổi Bật

### 1. 🎨 Typography & Hiệu ứng Chữ Triệu View (Creator Style)
- **Hiệu ứng Chữ 3D**: Tùy chỉnh độ sâu (Depth), góc đổ bóng khối 3D sắc nét.
- **Viền Chữ & Double Stroke**: Viền kép dày kiểu MrBeast / Gaming Thumbnail giúp chữ nổi bần bật trên mọi nền ảnh.
- **CapCut Auto-Pill Highlight**: Đóng khối màu nền bo góc cho từ khóa chính trong tiêu đề.
- **Neon Glow & Drop Shadow**: Hiệu ứng chữ dạ quang phát sáng và đổ bóng mềm.
- **Bộ Phông Tiếng Việt Tuyển Chọn**: *Anton, Montserrat, Be Vietnam Pro, Bangers, Oswald, Outfit, Playfair Display, Caveat* không bị lỗi dấu.
- **Màu Chuyển Sắc (Gradient Text)**: Pha trộn màu rực rỡ.

### 2. 📐 Trải Nghiệm Canvas & Hỗ Trợ Thiết Kế Pro
- **Đổi Tỷ Lệ 1-Click**: `16:9`, `9:16`, `1:1`, `4:5` tự động tính toán kích thước chuẩn.
- **Safe Zone Overlay (Khung Vùng An Toàn)**:
  - *TikTok Safe Zone*: Đánh dấu vùng tránh bị che bởi nút Like, Comment, Caption và avatar.
  - *YouTube Safe Zone*: Đánh dấu vùng tránh bị tem thời lượng góc dưới che mất.
- **Live Platform Mockup Preview**: Xem trước ảnh bìa hiển thị thực tế trên giao diện điện thoại YouTube Mobile & TikTok For You Page.
- **Smart Magnetic Snapping**: Tự động dính trục tâm, đường kẻ căn chỉnh chính xác từng pixel.
- **Quản lý Layer Nâng Cao**: Kéo đổi thứ tự trên/dưới, khóa/mở khóa layer, ẩn/hiện, nhân bản layer.
- **Lịch sử Undo / Redo**: Hoàn tác và làm lại thao tác không giới hạn (phím tắt `Ctrl+Z`, `Ctrl+Y`).

### 3. 🖼️ Quản Lý Hình Ảnh & Sticker
- **Sticker Outline Glow**: Tạo viền trắng/viền màu phát sáng bao quanh chủ thể ảnh.
- **Bộ Lọc Màu Sắc**: Tùy chỉnh Độ sáng, Tương phản, Độ bão hòa, Vintage Sepia, Đen trắng.
- **Lật ảnh (Flip H/V)**, bo góc ảnh, cắt khung hình tròn.
- **Kho Elements & Badge**: Huy hiệu `🔥 HOT NHẤT`, `⭐ VIRAL TIKTOK`, `🎙️ PODCAST`, `✅ VERIFIED`, hình khối đồ họa, ngôi sao, mũi tên.

### 4. 🚀 Xuất File 4K & Lưu Trữ Dự Án
- **Xuất ảnh đa định dạng**: PNG (trong suốt/sắc nét), JPG (tối ưu dung lượng), WebP.
- **Tùy chọn độ phân giải**: 1x Tiêu chuẩn (1080p), 2K Sắc nét, **4K Siêu nét**.
- **Lưu & Khôi phục dự án**: Tải file `.cover` (JSON) về máy tính để mở ra chỉnh sửa tiếp bất kỳ lúc nào.

## 🚀 Hướng Dẫn Chạy Ứng Dụng

Khởi động môi trường phát triển:
```bash
npm run dev
```
Mở trình duyệt tại địa chỉ: `http://localhost:5180` (hoặc cổng tự động do Vite phân bổ)

Đóng gói production:
```bash
npm run build
```
